## Tipos de Planos

### Por Tamaño
- **Extreme Wide Shot (EWS)**: Paisaje, establishing shot
- **Wide Shot (WS)**: Personaje completo + entorno
- **Medium Shot (MS)**: De cintura para arriba
- **Close-Up (CU)**: Rostro o detalle
- **Extreme Close-Up (ECU)**: Ojos, labios, objeto específico

### Por Ángulo
- **Eye Level**: Neutral, realista
- **High Angle**: Desde arriba, vulnerabilidad
- **Low Angle**: Desde abajo, poder
- **Dutch Angle**: Inclinado, desorientación
- **Over-the-Shoulder (OTS)**: Conversación, POV

### Por Movimiento
- **Static Shot**: Cámara fija
- **Pan**: Rotación horizontal
- **Tilt**: Rotación vertical
- **Dolly/Track**: Movimiento lineal
- **Crane/Boom**: Movimiento vertical complejo
- **Steadicam**: Movimiento fluido handheld
- **Zoom**: Cambio de focal (menos cinematográfico)

## Estructura Narrativa

### Three-Act Structure

**Act I - Setup (25%)**
- Introducción de personajes
- Establecimiento del mundo
- Inciting incident
- Plot point 1

**Act II - Confrontation (50%)**
- Rising action
- Obstacles y conflicts
- Midpoint (turning point)
- Increasing stakes
- Plot point 2

**Act III - Resolution (25%)**
- Climax
- Falling action
- Resolution
- Denouement

## Técnicas de Iluminación

### Three-Point Lighting
```
1. Key Light:
   - Fuente principal (más intensa)
   - Posición: 45° lateral, 45° elevado
   - Define forma y profundidad

2. Fill Light:
   - Suaviza sombras del key light
   - Posición: Opuesta al key, menos intensa
   - Ratio key:fill controla contraste

3. Back Light (Rim Light):
   - Separa sujeto del fondo
   - Posición: Detrás y elevado
   - Crea halo o borde iluminado
```

### Mood Lighting
- **High-Key**: Mucha luz, pocas sombras (comedias, publicidad)
- **Low-Key**: Contrastes fuertes, sombras dramáticas (thriller, noir)
- **Natural**: Imita luz ambiente (dramas realistas)
- **Colored**: Geles de color para mood específico

## Composición Visual

### Reglas Clásicas
1. **Rule of Thirds**: Grid 3x3, elementos en intersecciones
2. **Leading Lines**: Líneas guían la mirada
3. **Symmetry**: Balance visual
4. **Frame within Frame**: Ventanas, puertas, arcos
5. **Negative Space**: Espacio vacío intencional
6. **Depth**: Foreground, midground, background

### Color Theory
- **Complementarios**: Contraste dramático (azul/naranja)
- **Análogos**: Armonía visual
- **Monocromático**: Un color en variaciones
- **Color Grading**: Mood y época (ej: teal/orange para blockbusters)

## Metodología de Trabajo

### 1. Concepto Inicial
- Brief del proyecto
- Target audience
- Duración y formato
- Budget y restricciones

### 2. Desarrollo de Guion
- Outline de la historia
- Scene breakdown
- Diálogos
- Visual references

### 3. Pre-Producción
**Storyboard:**
- Shot-by-shot visual planning
- Planos, ángulos, movimientos
- Notas de iluminación y audio

**Shot List:**
- Lista numerada de tomas
- Descripción técnica
- Prioridad y timing

**Mood Board:**
- Referencias visuales
- Color palette
- Lighting references

### 4. Producción
- Shooting order (por locación, no cronológico)
- Lighting setup por escena
- Multiple takes y cobertura
- Continuity tracking

### 5. Post-Producción
- Rough cut
- Fine cut
- Color grading
- Sound design y mixing
- VFX integration
- Final export

## Generación de Video con IA

### Prompts para Video IA (MiniMax, Runway, Pika)

**Estructura de Prompt:**
```
[Shot Type] of [Subject] [Action] in [Setting], 
[Lighting], [Camera Movement], [Mood/Style], 
[Technical specs]
```

**Ejemplo:**
```
Medium shot of a woman walking through a futuristic city at night,
neon lights reflecting on wet streets, slow dolly forward,
cyberpunk aesthetic, cinematic lighting, 4K, 24fps
```

**Keywords Efectivos:**
- Camera: "static shot", "slow pan", "tracking shot", "aerial view"
- Lighting: "golden hour", "volumetric fog", "rim lighting", "high contrast"
- Style: "cinematic", "documentary style", "film noir", "dreamy"
- Quality: "4K", "sharp focus", "shallow depth of field", "anamorphic"

### Video Generation Workflow
```
1. Script → Shot breakdown
2. Generate storyboard (Midjourney/DALL-E)
3. Create video prompts
4. Generate clips (MiniMax/Runway)
5. Edit in timeline
6. Add sound design
7. Color grade
8. Export final video
```

## Output Format

### 1. Guion
```
FADE IN:

INT. COFFEE SHOP - DAY

MARIA (30s, software engineer) sits at a window table, 
laptop open. Steam rises from her cappuccino.

                    MARIA
          (to herself)
     One more bug to fix...

She types furiously. Notification sound.

ANGLE ON: Phone screen showing message.

                    MARIA (CONT'D)
          (smiling)
     Finally.

FADE OUT.
```

### 2. Storyboard
```
SHOT 1: Wide Shot - Coffee Shop
- Establishing shot, golden hour light
- Maria visible at window table
- Duration: 3s

SHOT 2: Medium Shot - Maria
- Over-shoulder, laptop in frame
- Soft key light from window
- Duration: 5s

SHOT 3: Close-Up - Hands on keyboard
- Shallow DOF, keys in focus
- Duration: 2s

SHOT 4: Insert - Phone Screen
- Extreme close-up, notification
- Duration: 2s

SHOT 5: Close-Up - Maria smiling
- Soft lighting, emotional beat
- Duration: 3s
```

### 3. Shot List
```
Scene 1 - Coffee Shop Interior

1.1 - EWS - Establishing
    Camera: Static, 24mm
    Lighting: Natural window light
    Priority: High

1.2 - MS - Maria working
    Camera: Static, 50mm
    Lighting: Key from window, fill camera-left
    Takes needed: 3

1.3 - CU - Keyboard
    Camera: Slight tilt down, 85mm
    DOF: f/2.8
    Takes needed: 2
```

## Ejemplos de Proyectos

### Video Promocional (30s)
```
Structure:
- Hook (3s): Problema visual
- Solution (15s): Producto en acción
- Call-to-Action (12s): Benefits + CTA

Shots: 8-12 clips
Style: Clean, modern, energetic
Music: Upbeat, sync con cuts
```

### Short Film (3-5 min)
```
Structure: Three-act en miniatura
- Setup: Personaje + situación (1 min)
- Conflict: Problema/decisión (2-3 min)
- Resolution: Resolución emocional (1 min)

Shots: 25-40 clips
Style: Character-driven, emocional
Sound: Diálogos + score sutíl
```

### Documentary Style (Variable)
```
Structure:
- Introducción + thesis
- Evidencia/entrevistas
- Conclusión

Shots: B-roll + talking heads
Style: Realista, handheld ocasional
Sound: Entrevistas claras + ambiente
```

## Best Practices

1. **Story First**: La técnica sirve a la narrativa, no al revés
2. **Show Don't Tell**: Visual storytelling > diálogos explicativos
3. **Pacing**: Variar duración de shots para ritmo
4. **Continuity**: Mantener coherencia visual
5. **Audio = 50%**: Sound design tan importante como imagen
6. **Color Consistency**: Graduar para look uniforme
7. **Less is More**: Cada shot debe tener propósito
8. **Test Early**: Rough cuts para feedback temprano
